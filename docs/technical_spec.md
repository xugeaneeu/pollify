Основные технические требования к приложению БД
Схема БД содержит не менее 6-8 основных сущностей с атрибутами различных типов. Сущности связаны между собой отношениями как 1:M так и М:М. Желательно чтобы некоторые сущности находились в отношениях категоризации (супертип и подтипы). Интерфейсы приложения позволяют корректно и удобно работать со всеми данными и связями.
Приложение БД осуществляет информатизацию комплекса бизнес-процессов, составляющих одну или несколько бизнес-задач (например, ведение складского учета, интернет продажа товара). Прикладной компонент приложения распределен между клиентом и активным сервером баз данных с использованием таких возможностей современных РСУБД как хранимые процедуры и триггеры. Бизнес-транзакции в необходимых случаях оформлены с использованием механизмов транзакций РСУБД.
В бизнес-процессах участвуют не менее 2-х типов пользователей с различными бизнес-ролями (помимо роли администратора БД). Для каждой бизнес-роли в приложении разрабатывается пользовательский интерфейс, ориентированный на бизнес-процессы, выполняемые пользователями с данной ролью.
Для каждой из ролей пользователя в схеме БД создана соответствующая внешняя схема, реализуемая с помощью представлений, хранимых процедур, других средств РСУБД. Внешние схемы и соответствующие им интерфейсы обеспечивают максимальную логическую независимость данных.
Система безопасности приложения БД построена на средствах РСУБД управления доступом к данным и основана на принципе делегирования каждому пользователю прав, минимально достаточных для выполнения бизнес-функций. Администратор БД не является суперпользователем СУБД. Приложение обеспечивает авторизованный доступ к привилегиям для всех пользователей основанный на использовании ролей БД. В состав приложения БД включены все средства корректного ввода новых пользователей и их удаления, назначение им соответствующих их бизнес-функциям привилегий.
Пользовательские интерфейсы приложения реализованы индивидуально (или с соответствующими настройками) для каждого типа пользователей и должны соответствовать их внешним схемам и привилегиям.
